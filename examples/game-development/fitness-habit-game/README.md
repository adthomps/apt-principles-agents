# Fitness Habit Game

## Scenario

Complete a self-chosen, low-stakes habit and grow a small virtual garden.

## Audience

A beginner developer exploring optional habit coaching without medical or performance claims.

## Beginner Goal

Build a gentle check-in, local progress state, feedback, and reset.

## Core Game Loop

Choose a personally appropriate habit → optionally mark completion → receive garden feedback → reflect → return later.

## Minimum Playable Prototype

One user-defined habit, one daily optional check-in, seven visual growth states, local storage, edit/reset, and no notifications or health integrations.

## Suggested Stack

React for accessible forms and state, Canvas for a small visual garden, or Godot/Unity if desktop engine learning is the project goal.

[Player Experience](../../../principles/game-development/player-experience.md), [State and Saves](../../../principles/game-development/game-state-and-save-data.md), and [UI/HUD](../../../principles/game-development/game-ui-and-hud.md).

## Relevant Agents

APT Game Development Coach, Game UI Reviewer, Scope Guardian, and an appropriate health/privacy human reviewer if scope expands.

## Example Feature Roadmap

Habit entry → local state → garden feedback → edit/reset → accessibility/privacy review.

## What To Cut If Scope Grows Too Large

Medical advice, prescribed goals, streak punishment, calorie/exercise claims, wearables, social comparison, accounts, notifications, and cloud data.

## Open Questions

- How will language preserve autonomy and avoid shame?
- What privacy and health review is required if personal data or recommendations are added?
