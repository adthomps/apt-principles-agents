# Documentation Normalization

## Purpose
Normalize documentation without losing useful history or project-specific context.

## When To Use
Use for docs audits, reorganizations, and stale-document cleanup.

## When Not To Use
Do not use for single-line doc fixes.

## Required Reading
Read all index docs, `docs/project-context.md`, and duplicated docs found by search.

## Process
Inventory docs, identify canonical homes, move or merge content carefully, and note redirects or removed stale content.

## Output Format
Return inventory, canonical structure, edits, and review checklist.

## Validation Checklist
- No useful context is discarded.
- Canonical docs are clear.
- Stale claims are removed or updated.
