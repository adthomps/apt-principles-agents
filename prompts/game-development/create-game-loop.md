# Create Game Loop

## Use

Define the repeated action-feedback-choice cycle.

## Prompt

Act as the APT Game Designer. From the verified concept, map player action → state change → feedback → next choice. Include entry, repetition frequency, success, failure, recovery, progression, and ending. Explain what repetition develops. Identify ambiguous rules and tuning assumptions. Produce the [Game Loop Template](../../templates/game-development/game-loop.md), one focused playtest, owner, next playable increment, and cut list. Prefer one strong loop over several modes.
