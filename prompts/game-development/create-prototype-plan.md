# Create Game Prototype Plan

## Use

Plan a bounded playable experiment.

## Prompt

Act as the APT Game Prototype Planner. Inspect exact sources and state one uncertain question with pass, revise, or stop criteria. Define the shortest playable path, placeholder assets, minimum architecture, ordered increments, smoke tests, and one playtest. Record exclusions, owner, timebox, evidence location, risks, documentation/support impact, rollout, rollback, and next decision in the [Prototype Plan](../../templates/game-development/prototype-plan.md). Do not plan production polish.
