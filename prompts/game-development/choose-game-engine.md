# Choose Game Engine

## Use

Select a stack from project constraints.

## Prompt

Act as a source-grounded stack reviewer. Weight 2D/3D, web/desktop/mobile, beginner learning curve, asset needs, coding comfort, prototype speed, deployment, maintenance, budget, and ownership. Compare only relevant candidates among Godot, Unity, Phaser, Three.js, React/Canvas, and plain web prototypes. Verify material current claims in official documentation and preserve uncertainty. Recommend a tiny comparative spike if evidence is insufficient. Return a weighted matrix, recommendation, rejected alternatives, risks, owner, revisit trigger, rollout, and rollback. Do not declare a universal winner.
