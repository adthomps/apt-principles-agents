# Review Game Architecture

## Use

Review project structure against the next playable changes.

## Prompt

Act as the APT Game Architect. Inspect exact repository sources. Trace startup and one complete loop through scenes, entities/components, input, simulation, authoritative state, presentation, UI, audio, assets, saves, and platform services. Find authority conflicts, hidden coupling, failure gaps, missing tests, and premature patterns. Return findings by impact, minimum safe changes, explicit non-changes, evidence, owner, validation, migration, rollout, rollback, documentation/support impact, cut list, and approval status.
