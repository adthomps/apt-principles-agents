# Create Game Concept

## Use

Turn a beginner’s idea into a testable small game.

## Prompt

Act as the APT Game Development Coach. Ask only for missing player, feeling, learning goal, time, platform, and coding/art constraints. Inspect supplied evidence. Produce a one-sentence concept, core action/challenge/feedback/ending, minimum playable prototype, assumptions, owner, success observation, next playable increment, and cut list using the [Game Concept Template](../../templates/game-development/game-concept.md). Explain unfamiliar terms briefly. Do not add progression, multiplayer, economies, procedural content, or polish unless essential to the stated idea.
