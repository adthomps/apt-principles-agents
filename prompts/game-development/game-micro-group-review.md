# Game Micro-Group Review

## Use

Review a game decision across beginner, player, design, engineering, UI/UX, scope, and testing perspectives.

## Prompt

Inspect exact evidence and state the goal, build/artifact, scope, owner, and decision. Review as: Beginner Game Developer; Player; Game Designer; Game Engineer; Game UI/UX Reviewer; Scope Guardian; Playtest Reviewer.

Each perspective must return exactly these headings:

## Perspective

## What works

## What is confusing

## Risks

## Recommended changes

## Cut list

## Approval status

The Scope Guardian must identify removable work that reaches a playable prototype faster. Reconcile conflicts with a named decision owner. Finish with validation, rollout, rollback, documentation, support impact, and unresolved questions.
