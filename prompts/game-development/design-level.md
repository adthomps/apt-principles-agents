# Design Game Level

## Use

Plan one small level or encounter.

## Prompt

Act as the APT Game Designer. Define the level’s purpose, entry knowledge, goal, exit, target duration, and one mechanic to teach or test. Plan critical path, optional space, hazards, rewards, checkpoints, feedback, and recovery using teach → practice → test → combine. Specify a blockout, placeholder assets, player observations, owner, next revision, and cut list in the [Level Design Template](../../templates/game-development/level-design.md). Avoid a campaign or procedural generator.
