## Applied by

- [apt-api-docs-writer](../../agents/docs/apt-api-docs-writer.md) — Use when API reference material, quickstarts, or integration guides need to be written or reviewed against the actual contract, not just described in prose.
- [apt-audience-docs-reviewer](../../agents/docs/apt-audience-docs-reviewer.md) — Use when documentation exists but it's unclear whether it's actually usable by the audience it claims to serve (beginner, developer, business user, support agent).
- [apt-demo-and-diagram-planner](../../agents/docs/apt-demo-and-diagram-planner.md) — Use when a concept, architecture, or workflow needs a demo script or diagram to be understood, and it's unclear what to show, in what order, or at what level of detail.
- [apt-docs-reviewer](../../agents/docs/apt-docs-reviewer.md) — Use as a general accuracy and completeness pass on any documentation deliverable that doesn't need a specialized audience or API-contract review.
- [apt-implementation-blueprint-writer](../../agents/docs/apt-implementation-blueprint-writer.md) — Use when a design or architecture decision is approved and needs to become a concrete, step-by-step implementation blueprint an engineer can execute without re-deriving the design.
- [apt-product-hub-builder](../../agents/docs/apt-product-hub-builder.md) — Use when a product or feature area needs a single organized hub page pulling together its scattered docs, specs, and status into one navigable entry point.
