# Beginner Game Development

## Principle

Learn by finishing a tiny playable experience. A first project should teach one loop, one toolchain, and one release path—not simulate a studio.

## Apply The Four Pillars

- **Thinking:** name the player, desired feeling, constraints, and learning goal.
- **Design:** express the idea as actions, rules, feedback, and a clear end.
- **Architecture:** choose the smallest stack and structure that supports the prototype.
- **Execution:** build one playable increment, test it, record learning, and repeat.

## Practice

Write the idea in one sentence. Limit the first version to one main action, one challenge, one level or scene, placeholder assets, and a short play session. Keep a “not now” list. Ask a beginner reviewer to follow the setup and first task without hidden knowledge.

## Evidence Of Progress

A new player can start, act, receive feedback, and reach an ending. The developer can explain what was learned and name the next smallest change.
