# Level and Scene Design

## Principle

A level arranges challenges and learning over play; a scene is a runtime container for a place, interface, or game state. Use both to create a readable flow.

## Practice

Give each level or scene one purpose. Define entry, goal, available actions, teaching moment, challenge, feedback, failure recovery, exit, and transition. Introduce one idea safely, require it, then combine it with known ideas. Sketch flow before building detailed content.

## Scope Guardrails

Prototype one representative level or short scene sequence. Reuse modular pieces. Do not build a level editor, procedural generator, branching campaign, or large content library unless the core hypothesis requires it.

## Evidence

Players can navigate, identify the goal, use the intended mechanic, recover from failure, and reach the exit without author coaching.
