# Prototype-First Game Development

## Principle

A prototype is a disposable or evolvable experiment that answers a specific question. Its job is learning, not polish.

## Practice

Choose the riskiest assumption: control feel, readability, technical feasibility, or loop appeal. Set a timebox and a pass/fail observation. Build only the path needed to test it. Use simple shapes, generated data, and temporary audio. Playtest, capture evidence, then keep, revise, or discard the experiment.

## Prototype Versus Vertical Slice

A prototype proves an uncertain idea cheaply. A vertical slice demonstrates a small portion near intended production quality. Beginners should prototype first; a vertical slice is justified only after the loop and scope are credible.

## Exit Criteria

The experiment ends with a recorded decision, evidence, known limitations, the next playable increment, and an updated cut list.
