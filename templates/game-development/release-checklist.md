# Game Release Checklist

- [ ] Owner, build, scope, target, and approval recorded.
- [ ] Start-to-exit smoke path passes on target devices.
- [ ] Controls, pause, restart, failure, and recovery pass.
- [ ] Save/load/reset and failure behavior pass if present.
- [ ] Performance, resize, focus, accessibility, privacy, and security reviewed proportionately.
- [ ] Asset/code licenses and AI provenance reviewed.
- [ ] Known issues, player/developer docs, and support path published.
- [ ] Distribution/platform requirements verified from current sources.
- [ ] Rollout, telemetry/feedback, stop conditions, and rollback tested.
