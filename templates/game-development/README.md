# Game Development Templates

Use only the templates needed for the next decision. Keep entries brief, link evidence, and move optional ideas to the scope cut list.

- Concept and design: game concept, game design document, loop, mechanics, player journey
- Planning: prototype, scope cuts, levels, scenes, assets, learning
- Architecture: game architecture, state, saves, input
- Experience: UI/HUD and audio/feedback
- Validation: playtest plan/notes, release checklist, micro-group review
