## Candidate Decision Summary

- [Recommendation] Implement in Phase 1 after blockers are approved: five governance documents and a small `governance/README.md` index update.
- [Recommendation] Consolidate authority, lifecycle, and ADR convention into one document to avoid fragmented conflict rules.
- [Recommendation] Consolidate workflow convention, context packet convention, and future command specifications into one operating-conventions document.
- [Recommendation] Defer stale-reference cleanup for `CONTRIBUTING.md` and `docs/diagrams/repository-structure.md` unless explicitly included by human approval.
- [Recommendation] Reject or defer every new directory whose only reason is symmetry.
