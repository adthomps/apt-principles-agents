# Model Routing

Use cheap/local models for low-risk classification and summarization; strong models for architecture, payments, security, and major refactors; reviewers for final checks; humans for protected decisions.

Record owners, source links, assumptions, validation, and freshness. Use [APT principles](../principles/README.md) for decisions and [skills](../skills/README.md) for procedures.
