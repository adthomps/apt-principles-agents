# Getting Started

Start with the four pillars, select the relevant domain principles, choose a template and skill, then validate with the appropriate agent perspectives.

Record owners, source links, assumptions, validation, and freshness. Use [APT principles](../principles/README.md) for decisions and [skills](../skills/README.md) for procedures.

## Start A Small Game

Use the [Game Development start path](../principles/game-development/README.md), choose one concept and core loop, then reduce it to a minimum playable prototype. Select only the skills, agents, and templates needed for the next decision. Install the domain with the `game-development` manifest when useful.
