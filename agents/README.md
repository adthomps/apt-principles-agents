# APT Agents

Agents are accountable perspectives, not alternate doctrine or product/customer personas. The nine named roles keep the same responsibilities and authority as their predecessor roles; their names do not create new permissions or approval power. For important reviews return: **Perspective, Concerns, Recommended changes, Risks, Questions, Approval status**. The router selects the smallest useful group; a human retains approval for protected decisions.

For the role-versus-persona distinction and authoring criteria, see the [agent authoring guide](../docs/agent-authoring-guide.md) and [audience-layered documentation guide](../docs/audience-layered-documentation.md).
