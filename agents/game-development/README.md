# Game Development Agents

These agents are accountable perspectives, not substitutes for player evidence or human approval. Use the smallest useful group and include the Beginner Game Dev Reviewer for beginner-facing plans.

- Coach, Designer, Architect, and Prototype Planner
- Gameplay, Beginner, UI, Testing, and Documentation reviewers
- Scope Guardian
