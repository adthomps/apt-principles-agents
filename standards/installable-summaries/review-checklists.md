# Review Checklists

## General APT Review

- Scope is clear and intentionally limited.
- Existing behavior is preserved or intentionally changed.
- Project context has been consulted.
- Tests or validation commands are named.
- Generated content is useful and specific.

## AI Output Review

- No invented APIs, files, or business rules are accepted without verification.
- Security, privacy, and data retention claims are source-backed.
- Code follows the repo's existing patterns.
- Documentation distinguishes fact from recommendation.
