# Security Context Pack

Use for secrets, auth, payments, health data, webhooks, permissions, MCP tools, and repair operations.

Load:

- environment/config docs
- route handlers or integration clients
- logs and observability docs
- manifests and lifecycle reports
- security-sensitive tests

Require human approval before material security-impacting changes.
