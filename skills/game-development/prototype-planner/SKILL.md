# Prototype Planner

## Purpose

Turn uncertainty into the smallest useful playable experiment.

## When to Use

Use before building a new idea, mechanic, control model, technical approach, or experience.

## Inputs

Question, hypothesis, constraints, chosen stack, available assets, risks, and decision owner.

## Process

1. State one question and a pass, revise, or stop decision.
2. Define the shortest playable path and explicit exclusions.
3. Choose placeholders and the minimum architecture.
4. Break work into observable increments.
5. Define smoke tests and a playtest method.
6. Record timebox, owner, evidence location, rollout, rollback, and next decision.

## Outputs

Prototype plan, task sequence, acceptance criteria, risks, cut list, and evidence log.

## Quality Bar

The plan can answer its question without production polish or unrelated systems.
