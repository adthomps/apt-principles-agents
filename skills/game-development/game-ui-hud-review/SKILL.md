# Game UI HUD Review

## Purpose

Ensure interface elements help decisions without obscuring play.

## When to Use

Use for HUDs, menus, overlays, tutorials, settings, failure screens, or responsive layout.

## Inputs

Screens, target sizes, player goals, information hierarchy, controls, accessibility needs, and playtest evidence.

## Process

1. State the decision each element supports.
2. Rank information by urgency and frequency.
3. Trace start, play, pause, failure, success, settings, and restart.
4. Check contrast, type, focus, long text, redundant cues, and playfield protection.
5. Remove or defer low-value elements.
6. Capture findings, owner, validation viewport, support impact, and rollback.

## Outputs

Prioritized findings, annotated flow, accessibility checks, acceptance criteria, and cut list.

## Quality Bar

Players can find goals, important state, actions, and recovery without coaching.
