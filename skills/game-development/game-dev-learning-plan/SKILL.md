# Game Dev Learning Plan

## Purpose

Sequence concepts so a beginner learns them while producing visible playable progress.

## When to Use

Use when starting game development, changing engines, or recovering from tutorial overload.

## Inputs

Learner goal, prior coding/art experience, chosen stack, available time, accessibility needs, project idea, and official learning sources.

## Process

1. Define one learning outcome and one tiny game.
2. Assess prerequisites without assuming expertise.
3. Sequence setup, input, state, feedback, loop, scene flow, testing, and release.
4. Pair each concept with a playable exercise and reflection.
5. Use official references; defer unrelated engine features.
6. Schedule review, evidence, support, cuts, and the next project decision.

## Outputs

Milestone plan, exercises, source list, evidence checklist, help path, and cut list.

## Quality Bar

Every milestone creates something runnable and explains the concept in the learner’s own project.
