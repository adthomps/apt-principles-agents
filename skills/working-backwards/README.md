# Working Backwards Skills

Procedures for the [Working Backwards](../../principles/execution/working-backwards.md) method. Used by the agents in [agents/working-backwards/](../../agents/working-backwards/README.md).

- [Adopt Working Backwards In A Repository](adopt/SKILL.md): set up a repository's own version — repository profile, personas, package index, template — on top of the APT method.
- [Run Working Backwards Session](run-session/SKILL.md): start or resume a package and drive it to a build decision.
- [Critic Review](critic-review/SKILL.md): independent PASS or NEEDS REVISION against the rubric and profile overlay.
- [Package Status](package-status/SKILL.md): read-only status of one or all packages.
