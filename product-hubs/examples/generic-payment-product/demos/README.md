# Demo Assets

Demonstrate the primary intent, expected success, recoverable failure, permissions, support identifiers, and operational follow-through. Never hide unsupported or simulated behavior.

The ExamplePay demo uses synthetic tokens, amounts, processor responses, webhooks, and settlement fixtures. It covers idempotent authorization, capture, decline handling, timeout recovery, duplicate webhook suppression, support lookup, and reconciliation without calling a real payment service.

Use the [demo plan](demo-plan.md) for the audience sequence, evidence capture, and exit criteria. Never place production credentials, customer data, or unredacted processor diagnostics in a demo.
