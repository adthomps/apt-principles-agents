# Game Product Hub Extension

Use this extension when a game or interactive experience needs a durable, audience-layered home. Keep one verified project truth while giving players, beginner developers, game design/engineering, UI/UX, testing, release/support, and AI agents the detail they need.

## Suggested Contents

- `game-overview.md`
- `game-design-document.md`
- `player-guide.md`
- `developer-guide.md`
- `prototype-plan.md`
- `game-loop.md`
- `mechanics-map.md`
- `level-design.md`
- `scene-flow.md`
- `asset-list.md`
- `audio-feedback-plan.md`
- `input-controls.md`
- `game-architecture.md`
- `save-system.md`
- `playtest-plan.md`
- `release-checklist.md`
- `diagrams/`
- `demos/`

Start with the overview, loop, prototype plan, controls, architecture, playtest plan, and release checklist. Add the rest only when a real audience or decision needs it.

## Conditional Audience Layers

A game does not automatically need business/merchant, bank/acquirer/partner, API, migration, or operations guides. Add them when the project includes commerce, payments, accounts, online services, live operations, regulated data, external integrations, or developer APIs. Those additions require the relevant APT domain principles and reviewers.

## Quality And Readiness

Name owners, build/version, evidence, assumptions, freshness, accessibility, asset/code rights, validation, rollout, rollback, documentation, and support impact. Keep planned behavior separate from the current playable build. Include the Beginner Game Dev Reviewer and Scope Guardian before prototype approval.
